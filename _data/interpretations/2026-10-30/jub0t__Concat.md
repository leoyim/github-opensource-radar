## 1. 它解决什么问题

免费剪辑软件的通病是水印、账号、素材上传与订阅制；专业工具又太重、学习曲线陡。中间地带长期空缺：功能够用、纯本地、无水印，并且能被脚本批量驱动。Concat 补的就是这一块，且把「可编程」写进了产品定位——对外暴露 JSON-RPC 与 MCP。

## 2. 为什么是现在

今日 +224 星，65 天到 1.2 万星，增速在本期后端类排第二。Rust + FFmpeg 的组合让它能同时做到本地渲染与实时预览。同期 nyaterm、coucou、OpenMausBot 都在证明同一个形态：「本地优先 + 可被 agent 驱动」是这一波工具的共同选择，而不再是云服务加订阅。

## 3. 关键能力

- 无水印、无账号、无付费墙，纯本地运行且离线可用
- 本地 Whisper 自动字幕，可选模型规格与字幕样式
- 本地 TTS 与几秒样本的声音克隆
- 背景去除：人物、物体或手绘遮罩
- 关键帧动画（位置、缩放、旋转、透明度、音量、特效参数）与曲线编辑器
- 100 种 GPU 渲染特效、滤镜与转场，预览实时
- 磁性时间线、波纹编辑、冻结帧、变速
- JSON-RPC API 与 MCP，可被脚本与 agent 驱动

## 4. 架构与实现

Rust 主体负责时间线与工程模型，媒体处理走 FFmpeg 管线，预览与特效由 GPU 渲染；对外暴露 JSON-RPC 接口作为自动化入口，MCP 是 agent 接入的适配层。跨平台打包，26 种语言的 README 说明它已面向国际化分发。

## 5. 上手路径

1. 先用一段 2 分钟素材跑完整链路（剪切、字幕、背景去除、导出），这一步能暴露编解码与硬件差异问题
2. 写一个 JSON-RPC 脚本做批量导出，验证自动化的边界在哪里——这是它区别于同类软件的核心卖点
3. 声音克隆涉及他人声音的授权，商用前先确认权利来源
4. 留意 FFmpeg 版本与硬解码差异，同一工程在不同机器上导出结果可能不一致

## 6. 风险与边界

- 65 天的项目，稳定性与格式兼容性未经过长期验证，重要工程建议保留中间产物
- AGPL-3.0，二次分发与 SaaS 化受限
- 本地 Whisper 与 TTS 对显存/内存有要求，低配机器会退化到很慢
- 声音克隆的滥用风险由使用者承担，且难以在技术上设限

## 7. 谁该用 / 谁别碰

需要批量出短视频、又不愿把素材上传云端的创作者与小团队。追求精细调色的专业后期不在目标范围。
