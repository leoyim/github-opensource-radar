## 1. 它解决什么问题

个人财务工具要么是闭源订阅制，数据托管在厂商侧；要么是开源但功能单薄，难覆盖资产、负债、投资与预算的完整视图。曾经功能完整的 Maybe Finance 在 2023 年停止开发，代码虽开源却无人维护。

## 2. 为什么是现在

476 天、11,993 星、892 fork、896 个 open issue，本期日增 159。它的特殊性在于「血统」：README 直接交代了 Maybe Finance 投入近百万美元开发、2023 年中停更、托管版短暂上线后关闭的完整经过，并明确本仓库是社区 fork。这种把前史讲清楚的坦诚，反而成了它获得信任的基础。

## 3. 关键能力

- 资产、负债、投资与净值的统一视图，支持多账户与多币种
- 预算与交易分类，规则化自动归类
- 浏览器访问，另有 macOS 桌面应用、移动应用与 API 客户端
- 可被 LLM agent 通过 API 访问，便于做自然语言查询
- Docker 自托管，数据留在自己的服务器
- 多语言界面（德、西、法、日、韩、葡、俄、中）

## 4. 架构与实现

Ruby 技术栈，AGPL-3.0 许可，Docker 为主要部署方式。作为 fork，它继承了 Maybe 的产品完成度，同时承担了「上游不再修复」的全部维护责任：896 个 open issue 既是活跃度的体现，也说明历史债务与安全补丁都压在社区身上。README 明确标注 fork 关系与署名要求，合规姿态清晰。

## 5. 上手路径

1. 按 docs/hosting/docker.md 用 Docker 部署，先在本机跑通再考虑公网

3. 配置资产与负债账户，确认净值计算口径符合预期
