## 1. 它解决什么问题

把主机游戏搬到手机上，传统路径是模拟整台机器，代价是性能损耗与巨大的兼容工作量；而 ARM 设备之间本可原生执行，缺的只是平台服务。

## 2. 为什么是现在

46 天、5,385 星、1,355 fork，C、MIT。它直接运行玩家自购的 Switch 版游戏 aarch64 程序，由小型宿主提供系统调用、文件系统、图形、音频与输入；触控整套重做，Android 侧用 Vulkan 重写图形，骁龙 8+ Gen 1 上营地和牛关中位 60 fps。

## 3. 关键能力

- 原生执行：游戏自带 aarch64 程序直接跑在设备上，无 CPU 模拟
- 平台服务层：系统调用、文件系统、图形 API、音频与输入由宿主提供
- 触控重做：完整触控方案，iPhone 与 iPad 全屏显示
- Android 侧 Vulkan 图形重写，社区移植
- macOS 原生版，支持键鼠与手柄
- 仓库不含任何游戏内容，需自备游戏文件

## 4. 架构与实现

以 C 编写的小型宿主加载游戏可执行文件，按需拦截并实现平台调用；图形层在 iOS 走 Metal、Android 走 Vulkan，输入层把触控映射为游戏输入，因此无需指令翻译。

## 5. 上手路径

1. 先确认自己持有合法的游戏副本与对应平台版本
2. 按 README 的分平台步骤准备资源，不要混用不同版本的游戏文件
3. 先用最低画质验证稳定性，再逐步提高分辨率与帧率
4. Android 侧注意 GPU 驱动差异，帧率结论只对特定芯片成立
