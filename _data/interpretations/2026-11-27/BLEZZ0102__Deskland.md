## 1. 它解决什么问题

桌面美化长期是静态的：换一张壁纸，图标依旧压在风景上，遮住主体、破坏构图；手工排版又无法应对图标增删与分辨率变化。

## 2. 为什么是现在

33 天、657 星、82 fork、12 issue、日增 +5，GPL-3.0。它按图标的真实位置实时重绘沙滩、草地、云影与投影，移动或增删图标时场景随之变化，不用 AI、不需要账号与 API Key；Preview 版即完整功能，非限时试用。

## 3. 关键能力

- 图标感知：读取桌面图标真实位置，移动时平滑过渡
- 两套完整主题：Beach 与 Meadow 的全部设置可调并跨会话保存
- 桌面集成：托盘控制、开机启动、窗口最大化或全屏时自动暂停
- 隐私导出：分享图与动画统一使用示例图标与色块，不截取真实桌面
- 独立安装：自有目录、设置、启动项与实例标识，可与其它版本共存
- 中英双语，无需登录

## 4. 架构与实现

Windows 宿主程序加 WebView2 渲染层：C# 侧读取图标布局并驱动窗口，前端负责场景绘制与过渡动画；Preview 采用独立安装标识，避免与正式版互相覆盖。

## 5. 上手路径

1. 先在 1080p 下确认图标栅格与场景比例的对应关系，再看高分屏
2. 移动几个图标，检查过渡是否跟随而非跳变
3. 全屏应用时确认自动暂停生效，避免占用 GPU
4. 对外分享前用内置导出，不要直接截图桌面

## 6. 风险与边界

- 仅覆盖 Windows，且依赖 WebView2 运行时
- 图标布局的读取方式可能受系统更新与第三方桌面工具影响
- GPL-3.0 对二次分发有约束，主题创作者需注意
- Preview 与后续版本的授权边界尚未明确，长期可用性待观察

## 7. 谁该用 / 谁别碰

在意桌面观感、愿意为一个细节工具投入配置时间的 Windows 用户；做桌面交互实验的开发者。
