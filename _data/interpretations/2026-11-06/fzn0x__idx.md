## 3. 关键能力

- 提供印尼 IDX / IHSG 行情、基本面与筛选能力
- CLI 表格输出便于人读，另有 JSON 模式供脚本处理
- 内置 MCP server，可由 AI agent 直接调用
- 单二进制分发、无需申请 API key
- 可配合 jq 等命令行工具组成数据管道

## 4. 架构与实现

Rust 实现、MIT 许可，三种输出形态共用同一套数据访问层，差别只在呈现：终端表格、结构化 JSON、MCP 工具描述。取舍是把范围收窄到一个市场，换来免鉴权、部署简单与接口稳定。README 示例明确标注行情为延时数据且显示最后成交时间，使用时应以时间戳判断时效。

## 5. 上手路径

1. 下载二进制跑一次 stocks quote，核对输出字段与时间戳
2. 用 JSON 模式接 jq，写一条简单的筛选管道
3. 在 MCP 客户端注册该服务，让代理完成一次查询
4. 再评估数据延时是否影响自己的使用场景
