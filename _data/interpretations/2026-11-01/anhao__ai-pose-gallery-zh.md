## 1. 它解决什么问题

做角色生图时参考素材是散的：原站由日本画师ギア拆成姿势、服装、人像三个独立站点，元数据全为日文，拼提示词要先翻译再对齐分类；外链图床不稳定，也不能离线用。这个仓库做的事很朴素——把 8,690 张图全部镜像进仓（姿势 2,878、服装 2,814、人像 2,998，人像为 1600×2000 高清 WebP），元数据逐条重译为中文，动作体系、服装款式、人像分区、发长与 51 种细分发型都给了中文标签，组装出的提示词没有日文残留。

## 2. 为什么是现在

仓库 5 天新建、4,802 星，尚无快照基线，热度按创建速度估算，属于典型的「解决刚需后被迅速转发」。触发点大概率是 v2.0 把三件事一起发了出来：三站合一、工作台、ComfyUI 原生节点——用户拿到的不是图库，而是从选参考到出图的完整链路。

## 3. 关键能力

- 三库全量本地镜像 8,690 张，含缩略图与高清原图，可纯离线浏览与静态托管
- 元数据 100% 中文化，姿势分类、服装标签、发长与 51 种发型均可直接拼进提示词
- Web Studio 支持人像+服装+姿势配方与一键随机捏人
- 支持拖拽、剪贴板粘贴与 URL 追加多张自定义参考图
- 五家图像协议直连：Gemini、GPT Image、通义千问、豆包、本地 ComfyUI
- 生成记录用 IndexedDB 本地持久化，不落服务端
- 同时是可 git clone 的 ComfyUI 自定义节点包，含 4 个节点与 4,345 张中文可视化选图器

## 4. 架构与实现

静态部分是 Cloudflare Pages 托管的文件树加 JSON 索引，无服务端逻辑，因此可整仓拷走离线用。Web Studio 是 React 19 + Tailwind 4 + TypeScript + shadcn/ui + TanStack Router 的多页应用，配方在客户端拼装为提示词，图像协议被抽象成五个适配器，key 由用户自带并只存本地。ComfyUI 侧是标准 custom_nodes 包，把图库检索与配方组装暴露为节点，选图体验用 WebView 弹窗复用了同一份索引。

## 5. 上手路径

1. 先只把仓库当离线索引层用：clone 后在本地起静态服务，确认 8,690 张图与中文标签的检索符合你的用法
2. 接图像协议前先把 key 的作用域收窄，别把主账号 key 放进浏览器环境
3. 用 ComfyUI 的话优先走节点而不是 Web Studio，节点在本地进程内调用，省掉一次跨域与凭据暴露
4. 抽查 20 条中文元数据的翻译质量，尤其是服装款式与发型这类细分标签，翻译偏差会直接进提示词

## 6. 风险与边界

- 图片版权归原作者ギア，仓库许可为 NOASSERTION，商用与再分发前必须取得授权
- 8,690 张高清图进 git 仓，仓库体积与 clone 成本不小，长期更新会持续膨胀
- 五家图像 API 的 key 在浏览器侧使用，任何 XSS 都可能带走额度
- 中文元数据由人工与模型翻译混合产出，细分标签存在偏差，会影响生图稳定性
