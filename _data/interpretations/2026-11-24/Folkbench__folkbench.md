## 1. 它解决什么问题

国内团队接入 Claude、GPT、Gemini 时常走第三方中转，但同一模型在不同站点的行为差异很大：是否被降级、可用率的统计时段、价格倍率的计价单位、退款条款的清晰度，都缺少可横向比较的公开口径；客户端侧的 Key 管理与多客户端切换也要手工维护。

## 2. 为什么是现在

3,542 星、上线 53 天、TypeScript、日增 108。README 没有停在「排行榜」，而是给出五条可逐项核对的评估口径与四条使用守则，并配套面向 Claude Code、Codex、Gemini CLI 的切换工具 Folkbench Switch——把口碑问题拆成清单，这一步比榜单本身更有价值。

## 3. 关键能力

- 中转站排行榜与可用性检测，按站点横向对比
- Claude / GPT / Gemini 的跨站比较，覆盖模型与分组维度
- README 内置五条评估口径：模型是否降级、可用率统计时段、价格倍率是否对齐币种与输入输出缓存三项、退款政策、先小额试用
- 四条使用守则：不囤大额、识别跑路信号、不外贴 Key、留意数据去向
- Folkbench Switch 支持在 Claude Code、Codex、Gemini CLI 等客户端间切换配置

## 4. 架构与实现

TypeScript 实现，仓库约 63 MB，包含静态站点与评测数据；评测结果以数据文件形式沉淀，前端为静态渲染；Switch 部分在本地改写各编码客户端的配置，不介入请求转发本身。
