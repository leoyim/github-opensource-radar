## 1. 它解决什么问题

Electron 类网页套壳应用动辄上百 MB、每个应用各带一份浏览器引擎；而 Nativefier 等方案配置繁琐。把常用网站变成独立桌面窗口，本应是一次命令的事。

## 2. 为什么是现在

1,492 天、63,584 星、13,002 fork，本期 +102，是移动端星标最高项。它与 apkstart 形成有趣对照：一个把安卓应用变成 Windows 窗口，一个把网页变成桌面窗口，共同指向「让现有内容以原生窗口形态存在」。

## 3. 关键能力

- 一条命令打包任意网站为 macOS / Windows / Linux 桌面应用，安装包通常小于 10MB
- 基于 Rust Tauri 与系统 WebView，不捆绑 Chromium，README 称体积约为 Electron 方案的 1/20
- 支持快捷键、沉浸式窗口、拖拽、样式自定义与广告移除，自动抓取网站图标
- 提供 CLI、在线构建、桌面应用与现成 Popular Packages，无需命令行也能用
- 面向 Claude Code / Codex 等 agent 场景给出用法，另有自定义开发与高级选项文档

## 4. 架构与实现

构建期用 Rust/Tauri 把目标 URL、图标与窗口参数编成轻量壳，运行期复用操作系统自带 WebView 渲染网页；样式与快捷键通过配置项注入，CLI、在线构建与桌面应用只是同一打包链的不同入口。

## 5. 上手路径

1. 安装 Pake CLI，用 pake <url> --name <名字> 打包一个常用站点，比较安装包体积
2. 验证快捷键、拖拽与沉浸式窗口，再按需注入自定义 CSS 去广告或调整布局
3. 需要分发时确认目标网站允许被嵌入与打包，检查图标与名称的使用授权
4. 有定制需求再 clone 仓库按 Advanced Usage 做二次开发

## 6. 风险与边界

- 依赖各平台系统 WebView，不同 OS/版本下渲染与能力支持会有差异
- 打包第三方网站涉及服务条款、商标与嵌入限制，分发前应取得相应许可
- 广告移除与样式注入可能违反目标站点条款，也可能随页面改版失效
- 6 个 open issue 极少，但 13,002 fork 说明定制分支多，问题常发生在下游配置
- GPL-3.0 对再分发的衍生应用有要求，商业打包前需评估

## 7. 谁该用 / 谁别碰

想把常用网页变成轻量独立桌面应用、并愿意用命令行做少量定制的开发者与重度用户。
