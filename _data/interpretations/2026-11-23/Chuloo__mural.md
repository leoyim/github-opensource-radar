## 1. 它解决什么问题

语言学习应用普遍把课程做成关卡，练的是记忆而不是使用；同时账号体系、云端记录与订阅把一件私人的事变成被追踪的产品。想「用自己钥匙、说自己的话」练口语，缺少合适的客户端。

## 2. 为什么是现在

本期 1,823 星、72 天，TypeScript 标注，SwiftUI + Jetpack Compose 双端，MIT。它自带 API key 直连模型、学习记录不出设备，属于「本地优先」在消费级应用里的一次具体实践。

## 3. 关键能力

- 与动画光球对话练习，按需查看语义提示
- 根据回复中的证据动态调整难度
- 后续对话中复现此前练过的词
- 十一套语言模块，iPhone 与 Android 双端
- 学习记录保存在设备，支持与 iPhone 兼容的 JSON 备份

## 4. 架构与实现

iPhone 端 SwiftUI（含 Liquid Glass 视觉），Android 端 Jetpack Compose；不设自有账号体系，直接以用户自备的 API key 调模型，学习状态以本地存储加可导出 JSON 的方式持有。

## 5. 上手路径

1. 准备好自己的模型 API key，先在 Wi-Fi 下跑一轮完整对话
2. 确认本地记录与导出备份的实际位置，纳入自己的备份策略
3. 用母语与目标语混合输入测试，观察纠错是否过度
4. 评估成本：对话时长直接对应 token 消耗，需设心理预算

## 6. 风险与边界

- 依赖用户自备 API key，模型侧政策或价格变动会直接影响可用性
- 记录仅在本机，设备丢失且未导出备份即不可恢复
- 语音识别与合成的质量受系统能力限制，口音场景表现不一
- 缺少账号体系意味着无法跨设备自动同步

## 7. 谁该用 / 谁别碰

愿意自带模型额度、重视数据私有、以口语练习为主要目标的学习者；不适合期望开箱即用课程体系的用户。
