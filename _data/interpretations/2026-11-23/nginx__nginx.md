## 3. 关键能力

- HTTP/1.1、HTTP/2、HTTP/3 与 TLS 终止
- 反向代理、负载均衡与内容缓存
- 邮件代理（IMAP/POP3/SMTP）能力
- 事件驱动的多进程架构，内存占用稳定
- 官方发行版与商业支持由 F5 提供

## 4. 架构与实现

master-worker 多进程模型，worker 以事件驱动处理连接，配置在启动或 reload 时解析为静态结构。仓库为上游源码快照，构建参数与模块选择决定最终能力集合。

## 5. 上手路径

1. 按官方文档从源码构建，先固定 configure 参数再谈调优
2. 用真实流量画像压测 worker_connections 与 keepalive 配置
3. 把 reload 纳入变更流程，验证旧连接是否平滑退出
4. 评估 HTTP/3 时先确认客户端覆盖与 UDP 策略

## 6. 风险与边界

- 源码仓库不等同于发行版，安全修复需自行跟进并重建
- 第三方模块与动态模块的 ABI 兼容性随版本变化
- 默认配置不适合直接暴露公网，需按官方安全建议收敛
- 商业版与开源版在部分高级能力上存在差异
