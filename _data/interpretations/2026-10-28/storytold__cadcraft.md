## 1. 它解决什么问题

CAD 是专业软件里最难被替代的一类：命令行输入、对象捕捉、图层、标注、填充、块、DXF 交换格式，这套工作流是几十年形成的肌肉记忆，换工具等于重学。开源 CAD 大多在这几处妥协——要么没有命令行，要么 DXF 兼容不全。CADCraft 的取舍是「这些全都保留」，再用纯 Rust 重写实现。

## 2. 为什么是现在

21 天、7,018 星，+98（快照口径）。它与同门的 designcraft 同日入选，而同系列在 10-26、10-27 期已连上 lightcraft、vectorcraft、effectcraft、figcraft。两周内六款「纯 Rust 重写专业创作软件」密集上榜，说明这是一条被系统化推进的产品线，而非孤立项目。判断这类项目的持续性，要看组织而非单个仓库。

## 3. 关键能力

- 命令行工作流：保留 CAD 的原生交互方式
- 对象捕捉、图层、标注、填充、块等标准能力
- DXF 图纸读写，可与既有工具交换
- 2D 与 3D 兼顾
- 四平台原生：macOS / Windows / Linux / FreeBSD
- WebAssembly 版本可在浏览器内运行

## 4. 架构与实现

纯 Rust 单代码库，渲染与几何内核自研，通过条件编译产出原生与 WASM 两个目标；DXF 作为外部交换层而非内部模型——这意味着它的几何表示是自己的，只在导入导出时做格式转换。四平台（含 FreeBSD）覆盖说明它没有依赖平台特定的 GUI 框架。

## 5. 上手路径

1. 先用 WASM 版本在浏览器里试命令行与捕捉手感，不需要安装
2. 用一份你熟悉的 DXF 做导入导出往返测试，确认几何与图层是否保真
3. 不要用于生产图纸：先确认它对你需要的标注样式与打印输出是否支持

## 6. 风险与边界

- 21 天新项目，工程制图所需的精度、标准件库、打印输出大概率不完整
- DXF 往返可能丢失信息，生产图纸风险高
- 同系列多产品并行，单项目维护带宽存疑

## 7. 谁该用 / 谁别碰

关注「专业桌面软件能否被纯 Rust 重写」的工程师；真正的制图生产环境请继续用成熟 CAD。
