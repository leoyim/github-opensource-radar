## 1. 它解决什么问题

桌面排版（DTP）是被商业软件长期垄断的领域：版面模型、字体渲染、分页与预印输出，每一块都有几十年的工程积累，开源替代品极少且大多基于既有框架拼装。DesignCraft 选择更难的路——不基于 Electron、不套壳，用纯 Rust 从零实现，同时产出原生应用与 WebAssembly 版本。

## 2. 为什么是现在

今日 +43 星（快照口径），27 天新库。单看热度它不突出，价值在于它是一条持续产品线的一环：同组织的 cadcraft 同日入选，10-26 与 10-27 期还有 lightcraft、vectorcraft、effectcraft、figcraft。六款「纯 Rust 重写专业创作软件」在两周内密集上榜，这不是巧合，而是一套被验证可复制的工程叙事。

## 3. 关键能力

- 页面排版与出版工作流，面向印刷与版面设计
- 原生运行 macOS / Windows / Linux
- WebAssembly 版本可在浏览器内运行，同一套代码
- 面向现代工作流设计，而非复刻旧软件的全部历史包袱
- 与 ArtCraft 系列其他应用共享底层（同团队、同技术路线）

## 4. 架构与实现

纯 Rust 单代码库，通过条件编译产出原生与 WASM 两个目标；渲染与布局层需同时满足桌面 GPU 与浏览器 WebGL/WebGPU 的能力边界，这是「同源双端」的主要约束。README 未披露具体的版面模型与字体栈细节，需读源码确认。

## 5. 上手路径

1. 先用 WebAssembly 版本在浏览器里试功能边界，不必先装桌面版
2. 评估它能否导入你现有的排版文件格式——不能导入意味着无法迁移既有项目
3. 若要参与贡献，先确认它的渲染后端抽象是否支持你熟悉的平台

## 6. 风险与边界

- 27 天的新项目，专业排版所需的功能（出血、色彩管理、预印 PDF）大概率不完整
- 无文件格式兼容性承诺，迁移成本可能高于收益
- 同系列多产品并行推进，单个项目的维护带宽存疑

## 7. 谁该用 / 谁别碰

关注「纯 Rust 重写专业桌面软件」这条技术路线的工程师；真正要做印刷排版的团队应继续用成熟工具。
