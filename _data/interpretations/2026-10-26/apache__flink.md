## 1. 它解决什么问题

有状态流处理要同时满足低延迟、事件时间语义、乱序容忍与 exactly-once，自研成本极高。Flink 用统一运行时同时支持流与批，并提供窗口、状态后端与反压机制。

## 3. 关键能力

- 流批一体运行时
- 事件时间与乱序处理（基于 Dataflow 模型）
- 灵活窗口：时间、计数、会话与自定义触发器
- exactly-once 容错与天然反压
- 图计算、机器学习与复杂事件处理库
- Java API 为主，另有 SQL / Python / Scala

## 4. 架构与实现

Java/Scala 实现，源码构建走 Maven（README 的 Building from Source 章节），支持 IntelliJ 与 Eclipse 开发；提供外部连接器生态。
