## 1. 它解决什么问题

跨系统传文件（Mac ↔ Windows ↔ Android）长期没有统一方案：要么依赖云盘（上传即离开本机）、要么靠数据线（不便）。LocalSend 用局域网发现 + 直连传输解决这件事。

## 2. 为什么是现在

今日 +127 星、95,697 星总量、3.9 年仓龄。与 RustDesk 一样属「常青刚需」：功能没变，但每次有新设备或新系统版本就会带来一波增量。

## 3. 关键能力

- 局域网直传：不需要互联网，不经过云
- 跨平台：Android / iOS / macOS / Windows / Linux（Flutter 一套代码）
- 文件与文本消息同时支持
- 提供 CLI 入口，便于脚本化
- 多语言界面与社区翻译流程

## 4. 架构与实现

Dart/Flutter 实现，靠局域网广播/UDP 发现对端、HTTP 直连传输；README 有 How It Works 与 Dependency Hierarchy 两节说明协议层与依赖分层，构建文档按平台分列。

## 5. 上手路径

1. 两台设备装好后放同一局域网，先确认发现是否正常（企业网/热点隔离常导致失败）
2. 传大文件时注意保持前台与屏幕常亮，移动端后台可能被系统挂起
3. 需要脚本化时用 CLI，把固定目录的传输写成命令

## 6. 风险与边界

- 依赖局域网广播，隔离型 Wi-Fi（访客网络、企业网）经常发现失败
- 传输默认为局域网明文/自签加密，不可信网络里需确认加密状态
- 移动端后台限制会影响长传输稳定性

## 7. 谁该用 / 谁别碰

适合经常在多设备间搬文件、且不接受上传云盘的用户；跨不同子网或需要断点续传的企业场景，应使用专门的传输系统。
