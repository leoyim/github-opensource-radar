## 1. 它解决什么问题

AI 生成设计稿的通病是「能看不能用」：图片不可编辑、风格不稳、品牌不搭。花叔设计把自己定位成 HTML 原生的设计技能，产出物是可直接交付的 HTML/可编辑 PPTX，并用「六个候选挑三个方向」的机制与 84 种带样张的风格库来压住「AI 味」。

## 2. 为什么是现在

26,820 星、今日 +251。Agent 技能（skills）正成为提示词工程的产品化形态，这类「把方法论打包成技能」的项目扩散极快；它同时也是中文社区里少见的、带大量真实案例（线上展、App 原型、讲座 PPT）的打包方案。

## 3. 关键能力

- 产出形态：网页、App 原型、可编辑 PPTX、动画、信息图
- 方向筛选：一次给六个候选缩略图，挑三个方向深化
- 84 种带样张的风格库，可作为兜底避免同质化
- 品牌资产接入：logo、色板、UI 截图，用于读取品牌气质
- 外观账本与设计体检：记录偏好并做产出检查
- 面向 Claude Code、Codex、Cursor 等编码 Agent

## 4. 架构与实现

以 skill 形式分发（Markdown 指令 + 资源库），依赖宿主 Agent 的读写与渲染能力；产物为 HTML 原生，因此可被浏览器直接打开、也可转成 PPTX。风格库与样张是核心资产，属于「提示词 + 参考物」的组合式实现。

## 5. 上手路径

1. 先跑一遍 README 的案例复现，确认你的 Agent 版本能稳定产出同类结果
2. 把品牌资产（logo、色板、截图）准备好再喂，能显著减少返工
3. 产出后必须人工过一遍品牌一致性与排版细节，不要直接发给客户
