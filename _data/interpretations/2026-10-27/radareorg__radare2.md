## 1. 它解决什么问题

逆向分析常在多个工具间跳转：十六进制编辑器、反汇编器、调试器、脚本 glue 各一套，批量分析难以自动化。radare2 把这些能力收进一套类 UNIX 的命令行工具与库，并用内嵌 JS 或 r2pipe 把分析流程脚本化。

## 2. 为什么是现在

25,165 星、今日 +8。它从「专注取证的十六进制编辑器」长成完整框架，是「窄工具 + 可组合命令」设计长期演进的样本；当前主线 6.2.5。对做恶意样本分析、固件审计的工程师，它仍是标配之一。

## 3. 关键能力

- 反汇编、调试、二进制分析与取证
- 命令行交互式工作流，命令可组合
- 脚本化：内嵌 JavaScript 解释器或 r2pipe 管道接口
- 库 + 工具 + 插件三层结构，插件各有许可
- 跨平台，支持源码构建与 Nix

## 4. 架构与实现

核心是一组库（IO、解析、分析、调试后端），工具层是命令行外壳，插件层扩展架构支持与可视化。README 明确「每个插件可有不同许可，可用 r2 -Lj 查看」，说明插件生态是松耦合的。

## 5. 上手路径

1. 先用包管理器装稳定版，按 README 的 Usage 章节跑一遍基础分析命令
2. 脚本化从 r2pipe 起步，比内嵌 JS 更容易与现有工具链集成
3. 涉及插件时先查许可，商用分发要逐个确认

## 6. 风险与边界

- 命令体系庞杂，学习曲线陡，官方书籍与文档是必需品
- 插件许可不统一，合规审查需逐项确认
- 版本迭代快，脚本可能随命令语义调整而失效

## 7. 谁该用 / 谁别碰

做恶意样本分析、固件与二进制审计的安全工程师；只做简单字符串提取的场景用轻量工具更快。
