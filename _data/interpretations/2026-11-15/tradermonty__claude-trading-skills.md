## 1. 它解决什么问题

个人投资者用大模型辅助研究时，往往靠临时提示词拼凑，分析口径、数据来源与输出格式每次都不同，也难以复盘；市面上的交易工具又多是黑盒策略，过程不可审阅。

## 3. 关键能力

- 覆盖市场分析、技术图表、经济日历、选股筛选与交易策略开发等核心技能域
- 给出推荐上手路径、示例输出与仓库结构说明，便于按需取用与改写
- 说明实际成本与无 API Key 的起步路径，降低试错门槛
- 可同时用于 Claude Web App 与 Claude Code 桌面端/CLI，附带配套工作包
- 以技能目录形式组织，纯文本可审阅、可版本化、可按自己的口径修改

## 4. 架构与实现

以 Claude Skills 的技能文件与目录结构为载体，把领域知识、分析步骤与输出模板写成 agent 可加载的文本；仓库按 Core Skill Areas 分域组织，配套工作包处理数据与示例，运行依赖宿主 agent 与用户自行配置的数据来源。

## 5. 上手路径

1. 先读 Disclaimer 与 Who This Is For，确认它与自己的投资方式（长期持有 / ETF / 股息为主、波段为辅）是否一致
2. 按 Recommended Starting Path 走一遍无 API Key 路径，用示例输出核对格式
3. 挑一个技能域（如经济日历）用自己的数据复跑，检查结论所依据的字段是否可追溯
4. 确认成本与数据来源后再考虑接入 Claude Code，把改动后的技能文件纳入自己的版本管理

## 6. 风险与边界

- README 明示这是投研流程辅助工具而非投资建议，输出不应直接作为交易依据
- 技能效果强依赖所用模型与接入的数据源质量，缺少实时数据时结论可能滞后
- 涉及行情与账户相关的配置时，需注意 API Key 与凭据不要随技能文件一并提交
- 策略开发类技能容易让人高估回测结论的适用范围，需自行做样本外验证

## 7. 谁该用 / 谁别碰

适合以长期投资为主、想用大模型规范研究流程并能自行核对数据的个人投资者与量化爱好者；不适合寻求自动下单或确定性收益预期的场景。
