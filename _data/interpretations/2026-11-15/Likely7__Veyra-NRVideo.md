## 1. 它解决什么问题

本地视频、采集卡画面与游戏串流的画质处理通常分散在播放器、滤镜插件与录制软件里，每一步都要单独配置，处理顺序与参数难以复现，也很难一次导出统一结果。

## 3. 关键能力

- 实时 GPU 处理链，覆盖超分辨率、降噪、HDR 与帧生成
- 输入源涵盖本地视频、图片、采集卡与游戏串流
- 提供列表模式与节点模式，可自行搭建处理链并调整顺序
- 支持采集、录制、导出，以及与 OBS 的联动配置
- README 给出 Install and upgrade、Sources and pages、Export、OBS and settings 等章节

## 4. 架构与实现

C++ 实现，围绕 GPU 处理节点组织管线：每一路输入作为一个源，超分、降噪、HDR、帧生成等作为可串联的节点，输出分别导向实时预览、采集录制与文件导出；节点模式让用户显式定义处理顺序，列表模式则提供简化路径。

## 5. 上手路径

1. 按 Install and upgrade 安装，先用一段本地视频跑默认管线，观察实时预览的延迟
2. 只开一个增强节点，与原始画面逐帧对比，确认效果与开销是否值得
3. 在节点模式里调整处理顺序，检查不同顺序对画质与帧率的影响
4. 需要采集或直播时按 Capture and streaming 与 OBS and settings 配置，并核对导出设置的色彩空间

## 6. 风险与边界

- 实时超分与帧生成对 GPU 型号与驱动版本敏感，实际帧率需在自己的硬件上复测
- README 以功能展示与版本亮点为主，部分效果描述带营销色彩，量化结论宜以自测为准
- 帧生成会引入额外延迟，交互式场景（如实时游戏）需要单独权衡
- 下载量统计包含源码包、校验文件与图片，不等同于活跃用户数，评估热度时应区分口径

## 7. 谁该用 / 谁别碰

适合做视频采集、串流与本地画质增强的 Windows 用户与内容创作者；不适合缺少独立 GPU、或对延迟极度敏感的实时交互场景。
