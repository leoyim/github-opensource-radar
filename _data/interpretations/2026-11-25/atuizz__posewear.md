## 1. 它解决什么问题

AI 生图的出图质量瓶颈常在素材组织：姿势靠搜图、提示词靠现编，组合无法复现。尤其做人物动作类生图时，姿势线稿与深度信息需要成对提供，零散素材拼不出稳定构图。

## 2. 为什么是现在

2,057 星、上线 25 天、JavaScript、MIT，fork 459。它的差异点是素材成对组织：12 类图库中姿势卡一面线稿一面深度图，同动作同机位，可两面一起喂给生图模型；组合可整组复制提示词与图片直链，也可经 MCP server 接入 agent 工作流。

## 3. 关键能力

- 12 类图库（姿势、服装、人像、表情、场景、光影、道具、家具等）配中英文提示词
- 姿势与深度图成对，卡片上点编号即可翻面，两面可同时用于生图
- 悬浮工作台：浏览时点 ＋ 收素材，攒够组合直接生图或整组复制直链
- 上传个人照片做 AI 试穿对比，生成记录可回看、下载、打包
- 提供 MCP server（codex mcp add posewear），图库可作为 agent 工具接入

## 4. 架构与实现

前端站点部署在 Cloudflare Pages，图库以静态资产加索引组织；生图调用外部模型服务，站内只做素材编排与组合管理；MCP server 以 node 运行本地仓库内脚本，向 agent 暴露图库查询接口。

## 5. 上手路径

1. 打开站点浏览姿势库，先按「动作 + 机位」筛选，确认线稿与深度图成对可用
2. 在悬浮工作台攒一组素材，直接站内生图验证提示词组合的稳定性
3. 把整组提示词与图片直链复制到自己的生图管线，对比与站内结果的一致性
4. 需要 agent 自动取素材时，本地跑 MCP server 并在 Claude Code 里注册后测试

## 6. 风险与边界

- 图库内容质量与版权状态依赖维护者，人像素材商用前需逐张确认授权
- 站内生图依赖外部模型服务，服务可用性与额度不由仓库控制
- 复制走的组合没有本地缓存，直链失效后需重新组图
- 上线 25 天的新仓，素材更新节奏与断链处理尚无长期记录

## 7. 谁该用 / 谁别碰

做人物与产品类 AI 生图的设计师与内容团队；需要把素材组合沉淀为可复用资产的创作者。
