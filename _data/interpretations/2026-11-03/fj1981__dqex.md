## 1. 它解决什么问题

银行、政企的内网机器往往装不了 JVM 和 Electron，也连不上外网下载依赖；但日常仍要做导入导出、跨库迁移、结构比对和数据字典。这类需求现有工具要么太重，要么必须联网。

## 2. 为什么是现在

「单二进制 + 离线可用」正在成为受限环境里选型的第一条，AI 辅助 SQL 又刚好能补上写方言差异的麻烦，两者叠加的需求最近明显。

## 3. 关键能力

- 单个静态二进制即可运行，无 JVM、无 Electron、无安装器，可拷到 U 盘带进气隙机房
- 导出、导入、迁移、结构比对、快照、Excel 数据字典、SQL 终端共用一套引擎
- MySQL、PostgreSQL、Oracle 三方方言自动转换，支持跨库迁移
- AI 助手先读真实表结构再生成 SQL，只产出文本；写操作必须确认，危险语句直接拦下
- 内置离线 SQL 模板库，模型未配置时功能自动降级而不报错

## 4. 架构与实现

Go 编译成静态二进制，Web UI 与 CLI 共用同一套引擎，等于把界面当客户端而不是运行时。AI 部分接 Eino 做编排，但把「生成」与「执行」拆成两步，执行前必须过一道确认，避免模型直接改数据。

## 5. 上手路径

1. 下载对应平台的单文件二进制，直接运行，浏览器打开本地端口即可用
2. 按 README 的 CLI in 30 seconds 先跑一次导出，确认连接串与方言识别正常
3. 拿一套测试库做结构比对与快照，验证它在自己环境里的差异识别是否准确
4. 要用 AI 功能再接模型；不接也能用模板库与 SQL 终端
