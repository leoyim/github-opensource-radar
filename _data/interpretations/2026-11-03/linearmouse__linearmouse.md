## 1. 它解决什么问题

macOS 的系统设置把滚动方向、加速度、灵敏度捆在一起，外接鼠标的滚动加速度尤其调不动；换一只鼠标就换一种手感，长期在 Mac 上用外设的人只能忍。

## 2. 为什么是现在

项目已持续维护五年多，7,113 星、198 个 fork，说明这类需求长期存在且没有官方解法；本轮因为新版 macOS 的兼容更新重新进入视野。

## 3. 关键能力

- 分别设置滚动方向、加速度曲线与灵敏度，可针对每只设备单独保存配置
- 支持按键与手势重映射，把侧键、中键接到自定义动作上
- 按设备区分配置，外接鼠标与内置触控板互不干扰
- 原生 Swift 实现，常驻菜单栏，不注入系统进程

## 4. 架构与实现

基于 macOS 的事件 Tap 机制拦截并改写输入事件，在系统处理之前调整滚动与指针参数。配置按设备标识存储，切换设备时自动套用对应方案。

## 5. 上手路径

1. 从 linearmouse.app 或 GitHub Releases 下载安装包，按提示授予辅助功能权限
2. 先在「滚动」页把加速度曲线调平，这是体感差异最大的一项
3. 为每只常用鼠标分别保存配置，避免换设备后手感错乱
4. 遇到权限失效时在系统设置的隐私与安全性里重新勾选
