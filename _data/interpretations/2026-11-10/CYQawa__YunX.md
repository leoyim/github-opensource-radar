## 1. 它解决什么问题

分享链接的取链、鉴权、下载与预览分散在多个环节：提取码要手填、直链常因缺少 Referer / Cookie 被拒、大文件断线要重下、图文笔记要一张张保存。想在一个 App 里连贯完成，需要把每个平台的差异和易碎点都兜住。

## 2. 为什么是现在

95 天 6,934 星、356 fork、53 个 open issue，本期 +133 为移动方向日增第一。README 把工程细节写得很实：Range 分片并发上限 32、任务保存请求头与固定分片规划以支撑断点续传、逐请求带 Referer / Cookie 解决直链 403、部分网盘取链后做临时转存清理，并单列技术栈、构建、常见问题与免责声明章节。

## 3. 关键能力

- 识别夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 光鸭 / 蓝奏云等分享链接并自动匹配提取码
- 解析短视频与图文平台的分享链接，输出可下载的直链
- Range 分片并发（上限 32）+ 断点续传，任务保存请求头与固定分片规划
- 图片 / 视频 / 音频在线预览，逐请求携带 Referer / Cookie 避免直链 403；网盘常见文本也可在线打开
- 图文笔记按两列网格铺开，支持翻页、双指放大、单张下载与长按多选批量下载
- 下载按整个文件夹或一次批量自动归组，下载页可折叠
- 临时转存清理：部分网盘取链后自动清理，另一些保留到下载完成或任务删除
- 多平台登录分别走 WebView Cookie、账号密码 / 短信验证码或换取 JWT

## 4. 架构与实现

Kotlin 实现、AGPL-3.0 许可，Android 原生客户端。工程重心在「链路稳定性」：解析层按平台适配登录与取链规则，下载层用固定分片规划 + 请求头持久化保证续传可复现，预览层在每次请求上补齐鉴权上下文，UI 层用两列网格与自动归组处理图文与批量场景。README 的功能、支持平台、技术栈、构建、常见问题是分开的章节，另有「反倒卖」与免责声明说明维护立场。356 fork、53 个 issue，属于使用面广、上游接口变化快的客户端类型。

## 5. 上手路径

1. 按构建章节自行编译或获取发布包，确认 Android 版本与权限要求
