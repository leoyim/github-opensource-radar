## 1. 它解决什么问题

让大模型参与交易决策，风险不在它能不能说出理由，而在它能不能突破既定的仓位上限、以及在调用失败时系统是否还能正常运转。多数「AI 量化」演示只展示结论，没有把「AI 只能更保守」和「故障硬回退」写成可验证的约束。

## 3. 关键能力

- 覆盖研究 → 策略 → 回测 → 风控 → 组合 → 交易 → 复盘的完整流程，含六维判势、多因子选股、策略回测、实时活动流与审计日志
- 五个 agent 组成 AI 投资团队：Planner 识别口语化问题并影响风险等级，CIO 层做多空辩论与 Kelly 仓位缩放
- 规则风控门：生效仓位取 min(规则, 主张, 异议, Kelly)，AI 只能让仓位更保守；单票上限按保守 15% / 均衡 20% / 成长 30% 分级
- 硬回退：LLM 未配置、失败或超时时完全回退规则决策；辩论方向、多空论据、共识度与 Kelly 系数写入可查的决策证据链
- 图形界面提供 AI 智能体决策、盘前到盘后的自动流程与活动流展示，v1.8.0 起决策脑合并进单个 exe

## 4. 架构与实现

Go 1.25 后端 + Wails v2 桥接 + React 18 / TypeScript / Vite 前端，本地用 DuckDB 存数据；Windows x64 以 ZIP 免安装包分发，配置行情与 LLM 的 API Key 后运行。README 徽章标注 Proprietary，仓库元数据为 NOASSERTION。

## 5. 上手路径

1. 从 Releases 下载 Windows x64 ZIP，解压后运行 QuantBot.exe，先不接任何实盘账户
2. 配置行情数据源与 LLM API Key，用历史数据跑一轮回测与模拟流程
3. 故意断开 LLM，验证系统是否按硬回退落到规则决策，并查看决策证据链是否完整
