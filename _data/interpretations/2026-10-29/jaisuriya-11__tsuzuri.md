## 1. 它解决什么问题

笔记工具的两难：Obsidian、Notion 这类体验好但把内容锁进自己的库与格式；vim + markdown 自由但完全没有块编辑、预览和导航。长期在终端工作的人被迫在「体验」与「可控」之间二选一。而多数 TUI 笔记工具又只做到「列表 + 编辑」，缺一个完整工作区该有的东西。

## 2. 为什么是现在

49 天 339 星，本期工具类第二（快照差值估算）。它踩中的是「纯文本 + 本地优先」这条持续升温的线：用户对云笔记的不信任在增加，而终端美学在小众群体里有稳定溢价。同期的 Terrascope 也是同类审美驱动。

## 3. 关键能力

- 笔记就是普通 .md 文件：无数据库、无锁定，可 git 管、可同步文件夹、可用任意编辑器打开
- 完整工作区：起始页、文件树、标签页、状态栏、97 套主题
- 模态键位编辑 + 鼠标支持，含未保存标签与另存为
- `/` 块菜单：标题、待办、表格、提示块（callout）、代码、图片等
- 预览按「页面」排版，支持语法高亮、图片与封面横幅，可直接在预览里拖动块排序
- 单二进制零依赖，覆盖 macOS（Intel/ARM）、Windows 10/11、x86-64 Linux，可导出 PDF

## 4. 架构与实现

Go 写的单二进制 TUI：以文件系统为唯一数据源（没有索引数据库，靠扫描目录构建文件树），编辑与预览共享同一份 Markdown AST，块拖拽是对 AST 节点的重排后回写文件。这个选择的直接后果是「所见即文件」——任何外部改动都会立刻反映，也不存在同步冲突。

## 5. 上手路径

1. 先在 ~/notes 这类已有 Markdown 目录上跑，验证它对既有文件的解析是否无损
2. 按 ? 看完快捷键表再动手，模态编辑的学习成本主要在前两天
3. 把目录纳入 git，这是它相对云笔记最大的优势，别浪费
4. Nerd Font 建议装上，否则图标会缺字

## 6. 风险与边界

- 无多端同步方案，需要自己用 git 或 Syncthing 解决
- 富媒体支持限于终端能渲染的范围，复杂表格与嵌入内容会退化
- 97 套主题是审美资产而非功能，长期只看它会形成同质化
- 49 天的新项目，大文件与大目录下的性能未经验证

## 7. 谁该用 / 谁别碰

长期在终端工作、笔记以纯 Markdown 为主、愿意用 git 做同步的人；需要多端实时同步与富媒体的用户不适合。
